Automated workflow to upload videos to YouTube using Google Sheets + Google Drive + YouTube API built with n8n (self-hosted).

🚀 Project Overview

This project automates the complete YouTube video upload process:

Reads video details from Google Sheets

Finds video file from Google Drive

Uploads video to YouTube automatically

Updates upload status back in Google Sheets

Runs on a scheduled trigger (Cron)

This workflow was built and tested on localhost (self-hosted n8n).
